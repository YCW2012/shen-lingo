# 非 Agent · 纯提示词版

| 项 | 值 |
|---|---|
| 内容 | 只有 `提示词.md`，不含任何图片 |
| 适合 | 平台**不支持传图**，或你懒得传图；只要能读文字就能用 |
| 表情包 | 30 个名称 + 情绪对照表，**全在提示词里写成文字** |
| 依赖 | 无。不联网、不装插件、不读文件 |
| 版本 | V0.0421（跟基线人设同号） |

## 和「含图片版」的差别

只差表情包那一节：本版是**文字名单**，AI 靠名字选图，看不到图长什么样，所以对"这张图到底是什么神态"只能按名字理解。
其余人设、规则、输出协议、状态卡**逐字相同**。

## 怎么用

1. 打开 `提示词.md`，**全文复制**。
2. 粘到网页端 AI 的「系统提示词 / 自定义指令 / 角色设定」；如果平台没有这个入口，就作为对话的第一条消息发过去。
3. 之后正常发消息即可，像发微信一样。

## 它产出什么

**纯文本气泡**，一条一个空行分开：

```
刚到家

外面好冷

〔表情包·抱抱〕
```

这不是 Markdown 效果，是**用排版模拟微信的"一条条蹦出来"**。不含 HTML、不含脚本、不写文件。

## 它做不到什么（提前说清，避免误会）

| 做不到 | 原因 |
|---|---|
| 生成可点开的聊天网页 | 网页端 AI 不执行代码、不写文件 |
| 把记忆存到下次对话 | 没有外部存储，只能靠「状态卡」手动存档 |
| 知道你现在的系统时间 | 只能从你的话里推 |

## 维护规则

- 人设部分与 `通用技能包/assets/persona.md` 保持同源：**改人设先改 persona.md，再同步到这里**。
- 表情包清单以 `通用技能包/assets/stickers.b64.json` 的 30 个键为准，不多不少。
- 版本号跟基线走（当前 V0.0421）。
