# 非 Agent · 含图片版

| 项 | 值 |
|---|---|
| 内容 | `提示词.md` + `图片清单.md` + `images/`（30 张表情包） |
| 适合 | 平台**能传图**，你想让 AI 真正"看见"表情包再选 |
| 表情包 | 30 张 jpg，文件名 = 名称（`开心.jpg`、`？.jpg`、`OK.jpg`…） |
| 依赖 | 无。图片只是随提示词一起上传的素材 |
| 版本 | V0.0421（跟基线人设同号） |

## 为什么带图

模型看不到图时，只能按名字猜"略"和"坏笑"的区别，选图容易跑偏。
把 `images/` 一起上传后，它见过每张图的神态，选得准，也更愿意用表情包而不是干巴巴的文字。

**本版不提供任何文字版"画面描述"**——文字描述必然失真，能看图就以图为准。

## 上传顺序

1. 先发 `提示词.md`（或粘进系统提示词）
2. 再把 `images/` 里的 30 张图一次性传进对话
3. 说一句「这些是你能用的表情包，之后按名字发」

之后用法与纯提示词版一致。

## 怎么用

1. 打开 `提示词.md`，**全文复制**。
2. 粘到网页端 AI 的「系统提示词 / 自定义指令 / 角色设定」；如果平台没有这个入口，就作为对话的第一条消息发过去。
3. 之后正常发消息即可，像发微信一样。

## 它产出什么

**纯文本气泡**，一条一个空行分开：

```
刚到家

外面好冷

〔表情包·抱抱〕
```

这不是 Markdown 效果，是**用排版模拟微信的"一条条蹦出来"**。不含 HTML、不含脚本、不写文件。

## 它做不到什么（提前说清，避免误会）

| 做不到 | 原因 |
|---|---|
| 生成可点开的聊天网页 | 网页端 AI 不执行代码、不写文件 |
| 把记忆存到下次对话 | 没有外部存储，只能靠「状态卡」手动存档 |
| 知道你现在的系统时间 | 只能从你的话里推 |

## 维护规则

- 人设部分与 `通用技能包/assets/persona.md` 保持同源：**改人设先改 persona.md，再同步到这里**。
- 表情包清单以 `通用技能包/assets/stickers.b64.json` 的 30 个键为准，不多不少。
- 版本号跟基线走（当前 V0.0421）。
