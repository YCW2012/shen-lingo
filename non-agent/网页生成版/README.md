# 非 Agent · 网页生成版

| 项 | 值 |
|---|---|
| 内容 | 只有 `提示词.md`，一段可直接粘贴的长提示词 |
| 适合 | **能生成网页、但只收纯文字**的 AI（如豆包爱学这类） |
| 输出 | 每一轮给你一整页自包含 HTML（深色微信聊天页） |
| 表情包 | 降级为大号 emoji 气泡（没有图片素材） |
| 记忆 | 无外部存储，靠模型自己记上下文 |
| 依赖 | 无。不联网、不装插件、不读文件、不跑脚本 |
| 版本 | V0.0421（跟基线人设同号） |

## 和另外两版的区别

| | 纯提示词版 | 含图片版 | **网页生成版** |
|---|---|---|---|
| 输出 | 纯文字气泡 | 纯文字气泡 | **完整 HTML 页面** |
| 需要模型能生成网页 | 否 | 否 | **是** |
| 需要传图 | 否 | 是 | 否 |
| 观感 | 靠文字排版模拟 | 同左 | **真的长成微信页**（深色、气泡、尖角、文件卡、红包卡） |

## 为什么需要这一版

前面几版的 agent 包要跑 Node、读模板、渲染 HTML —— 纯聊天型 AI 做不到。而另一类 AI（比如豆包爱学）
**能出网页，却只收纯文字**，既不能装技能包、也不能上传素材。

这一版把渲染器**写进提示词**：深色配色、气泡尺寸、尖角画法（4 个整数矩形）、
文件卡/红包卡结构、按天折叠与自动展开脚本，全部以代码片段的形式给到模型，让它照着抄。

## 已知边界（必须说清）

1. **每轮重出全量**。模型没有外部存储，页面里要含到目前为止的全部消息；超长时只保留最近 120 条并在页顶注明。
2. **表情包是 emoji**。没有 30 张图，只能用 emoji 气泡代替，观感与 agent 版不同。
3. **没有真正的记忆卷**。换窗口即失忆，只能靠对话上下文。
4. **模型可能偷懒**。真出现「以下省略」就重发一遍，或让它「重新输出完整 HTML」。

## 怎么用

1. 打开 `提示词.md`，**全文复制**。
2. 粘进豆包爱学的系统提示词 / 角色设定；没有该入口就作为第一条消息发送。
3. 之后像发微信一样说话，它每轮回你一整页 HTML（代码块），复制出来存成 `.html` 就能打开。

## 维护规则

- 改动要**两边同步**：本目录与 `自己用/非agent/网页生成版/` 内容必须逐字相同（非 agent 版无凭证，无差异）。
- 配色、尖角画法、卡片结构必须与 `agent/*/assets/chat-template.html` 保持一致，别自成一套。
- 改完先自己渲染一次：把提示词里给的示例 HTML 拼出来，用浏览器打开看尖角与卡片是否正常。
