# shen-lingo · 小深

微信场景里的 AI 扮演技能包。把「小深」挂到能跑 Node 的 AI Agent 上，她会读取历史与记忆、生成本轮回复，并渲染成一份**自包含的微信聊天 HTML 预览页**（产物名固定 `微信.html`）。使用者只看这个页面，不看 Agent 对话框里的文字。

版本 **V0.0521**。

## 分发件说明

- 本仓库是**对外分发版**，9 个包均已移除 IMA 凭证与作者知识库 ID。
- 有后端版本需要自备 `IMA_CLIENT_ID` / `IMA_API_KEY` 环境变量，或 `~/.config/ima/`；也可用 `XS_KB_ID` 指定知识库，否则自动发现使用者自己的库。
- 无后端版本用本地 `.xs_local/` 存储，不需要任何外部服务。
- 交付 HTML 为纯 ASCII、零外部请求，所有头像与贴纸内联 base64。

## 用法

1. 下载并解压对应 zip。
2. 找到含 `SKILL.md` 的那一层目录，把整层挂到 AI Agent 的技能目录。
3. 按 `SKILL.md` 的「每轮流程」执行；每轮只覆盖 `微信.html` 这一个文件。

## 页面内操作（有视觉版本）

在气泡上**右键**或**长按 500ms** → 菜单「复制 / 删除这条 / 多选 / 恢复全部 / 取消」。多选后可批量复制或批量删除。

删除与复制都是**纯前端行为**：删除只改显示层，记录写在浏览器 `localStorage`，不发网络请求、不改服务端数据。换设备或清缓存后消息会回来。

贴纸里另有一张 `赞赏码`（小深本人的赞赏码卡片），消息 `{"r":"shen","s":"赞赏码"}` 即可发出。

## 结构

每个 zip 内不含顶层文件夹，直接是 `SKILL.md` / `VERSION` / `CHANGELOG.md` / `scripts/` / `assets/` 等。

- `scripts/build_html.cjs` — 渲染 `微信.html`
- `scripts/xs_memory.cjs` — 读写聊天记录与记忆（有后端版本）
- `assets/chat-template.html` — 微信聊天页模板
- `assets/stickers_hd/` + `assets/stickers.b64.json` — 贴纸源图与内联 base64
