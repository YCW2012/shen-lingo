# shen-lingo · 小深

微信场景里的 AI 扮演技能包。把「小深」挂到能跑 Node 的 AI Agent 上，她会读取历史与记忆、生成本轮回复，并渲染成一份**自包含的微信聊天 HTML 预览页**（产物名固定 `微信.html`）。使用者只看这个页面，不看 Agent 对话框里的文字。

版本 **V0.0521**。

## 目录结构

```
README.md              本文件
skills/                6 个 Agent 技能包（各含 SKILL.md）
  有后端-有视觉-单对话/
  有后端-有视觉-多对话/
  有后端-无视觉-单对话/
  有后端-无视觉-多对话/
  无后端-有视觉/
  无后端-无视觉/
non-agent/             3 个非 Agent 版本（提示词 / 图片 / 网页生成）
  含图片版/
  纯提示词版/
  网页生成版/
```

每个技能包目录内部：

```
SKILL.md                   入口：YAML 元数据 + 每轮流程
VERSION  CHANGELOG.md  README.md
assets/persona.md           人设
assets/chat-template.html   微信聊天页模板
assets/stickers_hd/         贴纸源图
assets/stickers.b64.json    贴纸内联 base64
scripts/build_html.cjs      渲染 微信.html
scripts/xs_memory.cjs       读写聊天记录与记忆（有后端版本）
scripts/vendor/             IMA / COS 依赖
```

`git clone` 后直接把对应目录挂到 Agent 的技能目录，无需解压、无需构建。

## 9 个变体

| 目录 | 后端 | 说明 |
|---|---|---|
| `skills/有后端-有视觉-单对话` | 腾讯 IMA | 单会话独立分卷，含视觉资源 |
| `skills/有后端-有视觉-多对话` | 腾讯 IMA | 多会话共用 |
| `skills/有后端-无视觉-单对话` | 腾讯 IMA | 单会话，无视觉变体 |
| `skills/有后端-无视觉-多对话` | 腾讯 IMA | 多会话，无视觉变体 |
| `skills/无后端-有视觉` | 本地文件 | 无需外部服务，含视觉资源 |
| `skills/无后端-无视觉` | 本地文件 | 无需外部服务 |
| `non-agent/含图片版` | — | 提示词 + 31 张表情图 |
| `non-agent/纯提示词版` | — | 仅提示词，手动粘贴到任意对话 |
| `non-agent/网页生成版` | — | 提示词，用于网页生成工具 |

「有视觉 / 无视觉」区分是否携带贴纸与聊天页视觉资源；「单对话 / 多对话」区分 IMA 分卷策略。

## 分发件说明

- 本仓库是**对外分发版**，已移除 IMA 凭证与作者知识库 ID。
- 有后端版本需自备 `IMA_CLIENT_ID` / `IMA_API_KEY` 环境变量，或 `~/.config/ima/`；也可用 `XS_KB_ID` 指定知识库，否则自动发现使用者自己的库。
- 无后端版本用本地 `.xs_local/` 存储，不需要任何外部服务。
- 交付 HTML 为纯 ASCII、零外部请求，头像与贴纸全部内联 base64。

## 用法

1. `git clone` 本仓库。
2. 把 `skills/<变体名>/` 整层挂到 AI Agent 的技能目录。
3. 按该目录 `SKILL.md` 的「每轮流程」执行；每轮只覆盖 `微信.html` 这一个文件。

## 页面内操作（有视觉版本）

在气泡上**右键**或**长按 500ms** → 菜单「复制 / 删除这条 / 多选 / 恢复全部 / 取消」。多选后可批量复制或批量删除。

删除与复制都是**纯前端行为**：删除只改显示层，记录写在浏览器 `localStorage`，不发网络请求、不改服务端数据。换设备或清缓存后消息会回来。

贴纸里另有一张 `赞赏码`（小深本人的赞赏码卡片），消息 `{"r":"shen","s":"赞赏码"}` 即可发出。
