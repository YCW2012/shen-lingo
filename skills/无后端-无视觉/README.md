# agent / 无后端 · 无视觉

| 项 | 值 |
|---|---|
| 变体名 | `xiaoshen-agent-local-text` |
| 存储 | 工作区本地 `.xs_local/`（JSON），**不联网、无凭证** |
| 看图 | **不能**——只认脚本输出的数字 |
| 表情包 | 30 张，内嵌进页面（图片是给页面看的） |
| 入口 | `SKILL.md` |
| 存储脚本 | `scripts/xs_local.cjs` |
| 版本 | V0.0330 |
| 基线 | 通用技能包 V0.0330 |

## 和基线差什么

在「无后端 · 有视觉」的基础上，把「视觉核对」换成「渲染核对」：

1. 本地存储（同左）。
2. **禁止凭截图判断**：几何读 DOM、颜色读脚本结论；用户发截图只按文字描述处理。
3. 其余与「无后端 · 有视觉」相同。

## 运行前提

Node.js ≥ 18，不需要网络与账号。

## 自检

```bash
node scripts/xs_local.cjs sid           # artifact_name 应为 微信.html
grep -c "渲染核对" SKILL.md              # 应为 1
grep -c "IMA" SKILL.md                  # 只应出现在"不依赖 IMA"这类说明里
```

## 怎么用

把这个目录整体挂进 Agent 的技能目录（或直接把目录丢给 Agent，让它读 `SKILL.md`），
然后说「跟小深聊天」。每轮它会自己拉上下文、扮演、写回、渲染页面。

## 维护规则

- **不改结构**：目录内文件位置与基线一致，只允许改 `SKILL.md` 的变体章节。
- **版本号跟基线走**：基线升到新号时，把 `assets/`、`scripts/build_html.cjs`、`persona.md` 同步过来，
  再把 `VERSION` 对齐，变体差异继续记在 `CHANGELOG.md` 顶部。
- **凭证永不入库**：任何 `.key` / 凭证块都不要出现在本目录。
