# agent / 有后端 · 无视觉

| 项 | 值 |
|---|---|
| 变体名 | `xiaoshen-agent-ima-text-single` |
| 存储 | 腾讯 IMA（笔记 + 知识库），需联网与凭证 |
| 看图 | **不能**——只认脚本输出的数字 |
| 表情包 | 30 张，内嵌进页面（图片是给页面看的，不需要模型看见） |
| 入口 | `SKILL.md` |
| 版本 | V0.0330 |
| 基线 | 通用技能包 V0.0330 |

## 和基线差什么

1. 官网格没有凭证块（分发件不带 Key）；**自己用层在同一位置追加 `<!-- IMA-CREDENTIALS -->`**，并同步改写红线 11 与「环境依赖」第 3 条。对外分发前必须删掉该块。
2. **新增「渲染核对」小节**：禁止「看一眼就说改好了」，几何读 DOM、颜色读脚本结论、用户发截图只按文字描述处理。
3. frontmatter `name` 改成 `xiaoshen-agent-ima-text`。
4. 其余与基线逐字相同（含 30 张表情包——**页面照常显示**，只是不要求模型看图）。

## 运行前提

同「有后端 · 有视觉」：Node ≥ 18、能连 IMA、配好凭证。

## 自检

```bash
node scripts/xs_memory.cjs sid          # artifact_name 应为 微信.html
grep -c IMA-CREDENTIALS SKILL.md        # 官网格应为 0（自己用同格为 3）
grep -c "渲染核对" SKILL.md              # 应为 1
```

## 怎么用

把这个目录整体挂进 Agent 的技能目录（或直接把目录丢给 Agent，让它读 `SKILL.md`），
然后说「跟小深聊天」。每轮它会自己拉上下文、扮演、写回、渲染页面。

## 维护规则

- **不改结构**：目录内文件位置与基线一致，只允许改 `SKILL.md` 的变体章节。
- **版本号跟基线走**：基线升到新号时，把 `assets/`、`scripts/build_html.cjs`、`persona.md` 同步过来，
  再把 `VERSION` 对齐，变体差异继续记在 `CHANGELOG.md` 顶部。
- **凭证永不入库**：任何 `.key` / 凭证块都不要出现在本目录。
