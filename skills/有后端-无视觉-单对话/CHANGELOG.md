## V0.0111 — 2026-10-04
**增量：+0.0010（单点样式）**

- **修掉「尖角颜色与底色不一致」**：卡片底色收敛为唯一定义点 `.row .bubble.pay{--pay-bg:#e18d35}`（完成态 `#af6e29`），卡片本体与左右两侧小尖角统一取 `var(--pay-bg,#e18d35)`。此前两边各写一份颜色值，状态一多就会漏同步。
- `build_html.cjs` 新增 `payIsDone()`，按 `pay.status` 给气泡挂 `done` 类，尖角切色不再依赖 `:has()`；`?` 兼容分支保留，但 `:has()` 单独成条——与其它选择器写在同一列表里时，不支持 `:has()` 的浏览器会把整条规则丢掉。
- 顺带修掉同源问题：`@media print` 原来只把卡片底改成 `#f2f2f2`，尖角仍是深橙／深褐；现在改为覆盖 `--wx-bubble-*` 与 `--pay-bg` 变量，气泡底、文件卡底、支付卡底与全部尖角一起变浅。
- **尖角改由内联 SVG 绘制**：原先用 CSS `border` 画三角，45° 斜边被抗锯齿糊出一条「底色与背景色各半」的混色像素，在深色背景上就是尖角外沿那条深色描边 —— 即用户截图圈出的「尖尖颜色和底色不一致」。现在尖角是 4 个 1px 整数矩形拼成的阶梯，尖角像素只有两种颜色：底色本身与页面背景色，没有任何中间色。
- 尖角颜色改由 CSS 变量给 `fill`（卡片 `--pay-bg`、气泡 `--wx-bubble-*`、文件卡 `--wx-bubble-left`），与底色同源；左右两侧的形状由 `build_html.cjs` 直接生成互为镜像的整数坐标，不用 `transform:scaleX(-1)`（镜像重新采样会把抗锯齿带回来）。
- `build_html.cjs` 新增 `tailSvg()`，在四处气泡（左/右 × 支付卡 / 文字 / 文件）内各插入一枚 `svg.tail`；两种尖角都是 **4 宽 8 高、列高 2/4/6/8** 的阶梯，全部落在气泡外侧，位置与原边框三角一致（卡片离顶 13px、文字与文件气泡离顶 11px）。
- 形状用 4 个 1px 整数矩形拼，而不是 `<path>` 画三角：path 的尖端是「一个点」，光栅化取整时左侧那一列会被四舍五入掉（凸出只剩 3px）且左右不对称；整数矩形没有斜线，不依赖取整规则，凸出恒为 4px。
- **不需要 `shape-rendering="crispEdges"`**：整数矩形没有斜线可抗锯齿，加它是多余项。对照实验（同一页只多这一条声明，逐像素量）：加与不加**完全一致**，左右凸出都是 4px、剖面都是 2/4/6/8。旧版用 `border` / `<path>` 画斜边时它确实会连内容一起右移 1px（左侧凸出只剩 3px），那个结论**不适用于现在这套整数矩形**，别照旧结论去「修」。
- **验收证据（无头 Chrome，`--force-device-scale-factor=1`）**：屏幕模式与强制打印模式各跑一遍，覆盖 左/右 × 未领取卡片 / 已完成卡片 / 文字气泡 / 文件卡 共 10 组 —— 尖角外侧凸出**恒为 4px**，尖角那 4 列内除底色与页面背景外**无第三色**，总异常 0。成品页 `微信.html`（287 条、275 枚尖角、文档高 27433px）整页复检同为 0。
- 模板里 `.bubble::before`、`.bubble.pay::before`、`.bubble.file::before` 三组废弃的边框三角样式（含 `:has()` 版）一并删除，避免两套尖角同时存在。
- 为什么是 `+0.0010`：只动了颜色来源与一个状态类，属于单点样式修正，没有新增能力或改流程。
