# 变更记录 · 无后端变体 无后端-有视觉

> 本目录派生自「通用技能包 V0.0121」，**不独立占版本号**，`VERSION` 与基线同号。
> 基线自身的变更历史见 `通用技能包/CHANGELOG.md`；这里只记本变体相对基线的差异。

## V0.0521（2026-11-15）· 本轮改动
- **新增「赞赏码」贴纸**（`+0.0100` 新能力）：`assets/stickers_hd/赞赏码.jpg` + `stickers.b64.json` 增加 `赞赏码` 键；消息 `{ "r": "shen", "s": "赞赏码" }` 渲染为小深本人的赞赏码卡片贴纸（二维码 + 「小深 的赞赏码」）。纯内联 base64，零外部请求。

## V0.0421（2026-11-14）· 本轮改动
- **移植页面内菜单（删除/复制/多选/选区修复）**，与主力单对话版全功能对齐；纯前端 localStorage，不碰数据源、不发请求、不写凭证。
- 红线追加第 13 条：凭证禁注入 HTML、页面禁 fetch/直连 IMA/起服务。

## V0.0330（2026-11-06）· 本轮改动
- **新增 `protocol` 命令 + 版本锚**（`+0.0100` 新能力/流程改动）：解决「skill 更新后旧对话仍按旧措辞跑」的担忧。规则锚随 `read` 每轮返回并拼进 `content` 末尾，旧对话**无需重发 skill、无需新开会话**，下一轮即拿到最新版规则；`protocol sync` 把版本锚写进 store（幂等）。
- **优先级写死**：`protocol` 规则 > SKILL.md 正文 > 对话上下文残留旧措辞。新增「更新与重载」章节说明三层等价（数据外部 / 逻辑磁盘 / 规则注入）。
- **存储键冻结**：知识库、卷名前缀、sid 派生、`.xs_local` 路径跨版本不变，旧数据不失联。
- **更新范围约定**：自本版起只更新 `成品/自己用/`，官网层冻结不跟版；发布时由 `tmp/_publish_self_to_site.py` 从自用层派生并脱凭证。
- 明确**不做**包内 GitHub 自动自覆盖（云端技能目录常只读，运行中改自身指令不可靠），版本检测放在人这一侧。

## V0.0320（2026-11-06）· 本轮改动
- **预览卡交给平台自动出**：Trae/TIE 云端沙箱对写入工作区根目录的 `微信.html` **自动生成对话底部的预览卡片**（点卡片走内网网关 `remote-sandbox://<session>/workspace/微信.html?explorerUrl=…` 打开，可用）。渲染器产出的 HTML 首行已带 `<!-- Generated by Trae Work … -->` 标记，是触发条件之一。
- **正文彻底不输出链接/文件名**：删掉「`预览页：微信.html`」那行裸文件名——它在客户端只是一段点不动的蓝字，还容易让用户误以为能点。改为「正文可留白，或只说一句『已生成预览（对话底部会自动出现预览卡片）』」。
- **禁止 agent 自己起 HTTP 服务**：`python -m http.server` / `npx serve` 起的 `http://…` 地址在客户端同样点不动，纯属干扰；平台已有预览卡机制，不需要自建服务。
- **排查口径**：用户说「点了没反应」时，第一反应是确认文件落在工作区根目录、文件名是 `微信.html`、首行带 Trae 标记，而不是改交付话术或重跑。

（本条目覆盖 V0.0310 的「正文只留裸文件名」写法。）

## V0.0310（2026-11-01）· 本轮改动
- **文件只走 `f` 卡片**：用户这一轮带了文件，必须写成 `{ "r": "user", "f": { name, meta } }`，
  禁止用「（只发来一份说明，没说话）」这类旁白文字代替。一次多个文件 = 多条 `f`。
- **日期折叠条自动展开**：`chat-template.html` 监听 `scroll`，**向上滚动**且折叠条距视口下沿 400px
  以内时自动展开，一次只开一个并补偿滚动位置（往下翻不触发，不会一进来就摊平历史）；
  文字从「N 条 · 点击展开」精简为「N 条」。
- **折叠条去掉灰底胶囊**：改与时间戳同一行样式（12px / `--wx-time` / 居中），
  展开后整行降透明度、箭头翻转，不再是一个灰色按钮。
- **交付写法收紧**：正文只留 `预览页：微信.html` 裸文件名，禁止 `[微信.html](微信.html)`
  相对链接（客户端渲染成蓝字但点不动）；交付前必须 `ls -l` 自检字节数。
